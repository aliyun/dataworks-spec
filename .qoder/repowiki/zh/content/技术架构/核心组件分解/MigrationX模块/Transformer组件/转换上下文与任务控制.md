## 引言
本文档详细阐述了数据迁移系统中转换上下文与任务控制的核心机制。重点分析了ProjectWorkflowLoader如何构建转换上下文，包括项目资产、资源和工作流的加载过程。同时详细说明了Task和TaskDag如何实现转换任务的编排与调度，解释任务依赖关系的建立和执行流程。文档涵盖了任务状态管理（TaskStatus）、执行阶段划分（TaskStage）以及状态回调监听器（StateCallbackListener）的工作机制，展示了如何通过任务控制模型实现复杂的转换逻辑。

### Task 和 TaskDag 分析
Task和TaskDag共同实现了任务的编排与调度机制，通过依赖关系管理复杂的转换流程。

```mermaid
sequenceDiagram
participant TaskDag as 任务调度器
participant Task as 任务
participant Executor as 线程池
TaskDag->>TaskDag : init()
TaskDag->>TaskDag : handleTaskStageDepends()
TaskDag->>TaskDag : handleAnnotationDependsOn()
loop 注册所有任务
TaskDag->>TaskDag : registerTask(stage, task)
TaskDag->>Task : setStage(stage)
TaskDag->>Task : setTaskDag(dag)
end
TaskDag->>TaskDag : start()
loop 提交所有任务
TaskDag->>Executor : submit(futureTask)
end
loop 等待任务完成
Executor->>Task : call()
Task->>Task : setTaskStatus(WAITING)
Task->>Task : 等待依赖任务完成
Task->>Task : setTaskStatus(RUNNING)
Task->>Task : 执行业务逻辑
alt 执行成功
Task->>Task : setTaskStatus(SUCCESS)
else 执行失败
Task->>Task : setTaskStatus(FAILURE)
Task->>Task : 记录错误报告
end
end
TaskDag->>TaskDag : join()
TaskDag->>Executor : shutdown()
```
